# About — три согласованные правки

Изменены только data/about.php и существующие правила assets/css/about.css.
Источник изображений не редактировался. Обе иллюстрации подключаются mcp_asset_url().

- 01: оборудование увеличено ×1.18. На 1440: 294.36×220.77 → 347.34×260.5px.
  На узком desktop размер ограничивается доступным местом, без пересечения текста.
  Статистика сохранила все значения/подписи, выровнена вправо. Геометрия текущих
  текстовых колонок не перестраивалась; иллюстрация занимает свободную зону между
  копирайтом и статистикой. У flow-изображения на tablet/mobile сохраняется
  прежнее место в layout; увеличение через scale не растягивает секцию.
- 02: именно library/05-graphite-print-sheet-control.webp. Прежняя площадь поля
  сохранена через aspect-ratio879/887; содержимое нового 4:3 asset размещается
  object-fit:contain / object-position:center bottom, без деформации/обрезки.
  Небольшой сдвиг по существующему inset (38/4) совмещает нижние штрихи с переходом
  к 03: на 1440 видимый низ (alpha>32) примерно на 2px за границей секции.
- 03: размеры прежние. Привязка из системы Главной: right guide = --right +
  --client-nav-inset. На 1440 guide=82px от правого края, x=1358. Skyline и все
  значения/подписи статистики заканчиваются на этой оси. Footer/header не менялись.

Opacity всех иллюстраций .75; filter:none; нет рамки/фона/тени.
Hero, 04, footer, тексты, размеры/начертания шрифтов, вертикальные padding и
цвета сохранены. Ни Main, ни Services, ни общий CSS/сетка/логотипы не менялись.

server preview. Publish — после подтверждения пользователя. Не обходить лимит
и не делать независимые серверные изменения, не отражённые в work.
